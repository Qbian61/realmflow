# Composer 聚焦样式简化设计

## 目标

降低 Composer 获得焦点时的视觉强度。新对话页面与定时任务创建弹窗统一调整。

## 样式行为

- 普通状态保留现有轻微阴影和悬浮层级。
- 聚焦状态不增加外圈描边或强化阴影。
- 聚焦反馈仅通过内部白色输入区域的边框颜色变化表达。
- 输入区域边框由普通状态的 `#e3e3e3` 变为聚焦状态的 `#bcbcbc`。
- 保留现有 160ms 边框颜色过渡。

## 实现范围

仅修改 `src/styles.css` 中共享 `.composer` 的聚焦样式。由于新对话和定时任务弹窗复用同一个 Composer，两处会同步生效，不引入页面专属覆盖。

## 验证

- 自动检查聚焦规则不再定义 `box-shadow`。
- 新对话输入框聚焦时仅内部边框颜色变化。
- 定时任务弹窗中的输入框表现一致。
- 运行测试、类型检查和生产构建。

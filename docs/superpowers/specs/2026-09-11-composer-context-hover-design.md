# Composer 底部选择器悬停样式设计

## 目标

提升“选择工作空间”和“默认权限”两个底部选择器的悬停反馈。新对话与定时任务创建弹窗统一生效。

## 交互样式

- 默认状态继续使用现有灰色 `#737373`。
- 鼠标悬停任一选择器时，图标、文字和下拉箭头整体变为深黑色 `#222`。
- select 获得键盘焦点时使用相同的深黑色反馈。
- 不添加背景色、边框、阴影或位移动画。
- 颜色变化使用 150ms 过渡。

## 实现范围

仅修改 `src/styles.css` 中 `.composer-context .select-control` 的共享规则，通过父级 `color` 继承同步控制图标、select 文字和箭头。顶部模型选择器不受影响。

## 验证

- 样式测试确认 `hover` 与 `focus-within` 均设置 `color: #222`。
- 浏览器验证新对话和定时任务弹窗表现一致。
- 运行完整测试和生产构建。

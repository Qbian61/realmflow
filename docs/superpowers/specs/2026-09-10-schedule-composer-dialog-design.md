# 定时任务创建弹窗设计

## 目标

将定时任务创建入口恢复到页面右上角。点击入口后打开模态弹窗，弹窗内使用与“新对话”一致的输入框和功能控件。创建成功后关闭弹窗，并把新任务插入“进行中”列表顶部。

## 组件设计

### 共享 Composer

从 `NewChatPage` 和 `SchedulePage` 中提取通用 Composer 组件。组件负责：

- 文本输入框
- 添加文件、模式、技能和连接器菜单
- 模型选择
- 语音输入按钮
- 工作空间和权限选择
- 提交按钮及禁用状态

页面通过属性提供无障碍标签、占位文字、提交按钮名称和提交回调。组件不持有业务列表状态。

### 新对话页面

使用共享 Composer 替换原有内联结构，保留当前提示词提交、附件菜单和页面布局，不改变模板功能。

### 定时任务页面

- 页头右侧展示“新建定时任务”按钮。
- 删除底部固定 Composer。
- 点击按钮打开创建弹窗。
- 弹窗内渲染共享 Composer。
- 创建成功后清空输入、关闭弹窗，并将任务插入“进行中”列表顶部。

## 弹窗交互

- 支持右上角关闭按钮。
- 支持点击遮罩关闭。
- 支持按 `Esc` 关闭。
- 点击弹窗内容不会触发遮罩关闭。
- 输入为空时提交按钮禁用。
- 关闭后不创建任务。

## 样式

弹窗沿用现有模板弹窗的遮罩层级和居中方式，Composer 保持“新对话”的白色背景、圆角、边框、阴影与上下文操作栏。移除定时任务页面为底部停靠输入框预留的额外底部空间。

## 测试

- 定时任务页显示右上角创建按钮，初始不显示 Composer。
- 点击按钮后显示创建弹窗及其输入控件。
- 输入任务并提交后，弹窗关闭，新任务出现在“进行中”列表首位。
- `Esc` 和遮罩点击可以关闭弹窗。
- 新对话页面仍能输入并提交内容。
